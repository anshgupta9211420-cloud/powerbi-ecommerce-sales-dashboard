# 📊 Madhav E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview
This Power BI dashboard provides an interactive analysis of e-commerce sales performance, customer behavior, profitability, and regional trends.

The dashboard helps businesses monitor KPIs and identify high-performing products, customers, and states.

---

## 🚀 Key Metrics
- 💰 Total Sales Amount: 438K
- 📈 Total Profit: 37K
- 📦 Total Quantity Sold: 6K

---

## 📊 Dashboard Features
- Quarterly filtering
- State-wise sales analysis
- Monthly profit trends
- Category & sub-category performance
- Customer contribution analysis
- Payment mode distribution

---

## 🔍 Key Insights
- Maharashtra generated the highest sales.
- Printers and Bookcases contributed the highest profits.
- December showed the strongest monthly profit growth.
- COD and online payments dominated transaction methods.
